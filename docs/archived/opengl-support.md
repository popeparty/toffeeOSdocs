## OpenGL Support
OpenGL is natively supported **and** enabled by default in toffeeOS Developer Version 1.5 and earlier. OpenGL is supported **but not** enabled by default in toffeeOS Developer Version 1.6.1 and later.

For details, [see the Graphics APIs doc](https://github.com/popeparty/toffeeOSdocs/blob/master/docs/api/graphics.md).
