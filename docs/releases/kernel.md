## Kernel Versions

We tend to only use long-term support (LTS) releases of our kernel, with some limited exceptions for various variants of toffeeOS Developer Version, and/or short-term beta tests.

| toffeeOS Developer Version Release | Kernel Version |
|------------------------------------|----------------|
| 2.0 | 2610NX (x86_64) or 2610NA (arm64) |
